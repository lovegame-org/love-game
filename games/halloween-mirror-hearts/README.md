# Halloween Mirror Hearts

A Halloween-themed free browser challenge with hearts and mirror-style play. Short sessions, seasonal art — no install needed.

## How to play

1. Start the level and watch how hearts / mirrors react.
2. Match or move pieces according to the in-game rules.
3. Clear the board before you run out of moves (if limited).

**Tip:** Mirror layouts reward thinking in reverse — try flipping your plan.
