# Love Tester

A classic free browser love meter — enter two names (or nicknames) and get a playful compatibility score. Light, shareable fun for couples and friends; no download required.

## How to play

1. Open the game and enter two names.
2. Tap / click to run the tester.
3. Share the silly result — treat it as entertainment, not destiny.

**Tip:** Try nicknames or inside jokes for better laughs.

[Play Love Tester on love-game.org](https://love-game.org/games/love-tester/)
