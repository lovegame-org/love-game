# Love Game

Free love, couple & 2-player browser games — no download.

**Official site:** [https://love-game.org](https://love-game.org)

Love Game is a free HTML5 / browser game site for couples and friends. Pick a love tester, a co-op puzzle, or a Halloween special and play instantly — no install, no account required. Great for date nights, quick breaks, and two-player sessions on the same device.

## Games

- [Love Tester](games/love-tester/) — classic love meter / compatibility fun
- [Love Dots](games/love-dots/) — connect-the-hearts style puzzle
- [Halloween Love Game](games/halloween-love-game/) — spooky seasonal love pick
- [Halloween Mirror Hearts](games/halloween-mirror-hearts/) — mirror / hearts Halloween challenge
- [Fireboy and Watergirl: Light Temple](games/fireboy-and-watergirl-light-temple/) — 2-player co-op temple run
